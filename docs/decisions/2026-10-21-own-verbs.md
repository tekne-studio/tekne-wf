# wf's rules name wf's own verbs, never herdr's commands for the flow

**Decision:** The rules and the configs name `wf spawn`, `wf report`, `wf ship` and the rest; every herdr call goes through one adapter (`src/herdr.ts`), and agents use herdr directly only outside the flow.

**Why:** herdr is at 0.9, before 1.0, and its commands will change: with its own verbs, a herdr change is a new `wf` version, and the rules in every project stay as they are.

**Rejected:** rules that name herdr's commands for the flow: each herdr change would rewrite every project's rules
