# With an orchestrator, an agent's question goes to it, the person's filter

**Decision:** An agent asks by `wf ask`; the orchestrator answers what the decisions, the docs and the person's earlier choices settle, tells the agent and tells the person what it decided and why, and brings the person only a product question nothing settles, a permission, a push or a publish, or anything destructive or outward. Alone in a worktree, the agent asks the person.

**Why:** The person wants to be called only when needed (portrait.md, what the first round taught), and what already exists settles most questions; telling the person keeps every answer given in their name in view.

**Rejected:** every agent asking the person directly, as an agent alone does: the person would be called for what the decisions and the docs already answer
